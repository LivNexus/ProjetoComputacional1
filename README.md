<h3> ⚙️HelpTech </h3>


+ O HelpTech é o nosso projeto para essa atividade.
+ O sistema permite cadastrar clientes, funcionários e equipamentos, além de criar e acompanhar ordens de serviço
+ HelpTech tem como <b> objetivo </b> auxiliar na organização das informações de uma assistência técnica.

<h3>🖊️ Temas Abordados:</h3>

+ Classes e Objetos
+ Encapsulamento
+ Herança
+ Abstração
+ Polimorfismo

<h3>🔧 Tecnologias Utillizadas:</h3>

+ Python – linguagem utilizada no desenvolvimento do sistema;
+ Visual Studio Code (VS Code) – ambiente utilizado para desenvolvimento e edição do código;
+ Lucidchart - utilizado para elaboração do Diagrama de Classes
